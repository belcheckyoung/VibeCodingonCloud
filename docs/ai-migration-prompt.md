# 让 AI 修改默认存储位置

这段提示词来自一次配置中的教训，尚未经过完整实测。把尖括号里的内容换成你的实际情况。

```text
我已把网盘挂载到 Mac，路径是 <挂载路径>。
我想把 <工具名称> 的默认存储位置改到 <目标目录>。

先只做只读盘点，不要修改、移动或删除文件：
1. 按官方文档确认修改方法，并给出链接。
2. 列出当前路径、总体积和文件数。
3. 标出可能含凭据或会话记录的路径，不要打开或输出内容。
4. 指出不适合放云盘的目录。
5. 给出迁移和回滚方案，区分事实和推测，然后等我确认。

我确认后，先复制一个小目录测试，不删除原文件。
密码和令牌都由我自己输入。
```

不要把这些内容放进同步目录：令牌、API 密钥、`.env`、AI 工具配置和会话记录、`.git`、`node_modules`、缓存、构建产物，以及正在运行的数据库。
